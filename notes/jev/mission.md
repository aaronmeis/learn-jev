# Mission — Jev (TypeSafe System One) — typed decisions for software

## Why

One focused day to reach **working fluency** in TypeSafe AI’s **Jev** — the first **System One** model: fast, typed, probabilistic decisions for software (not chat). Correct the intake tip “typescript.ai” → **typesafe.ai**. Sibling context: [[ai-assistance-vs-automation]] (Almeida / RLHF → automation gap); this day is the product class and API shape.

## Success looks like

- [ ] Can state core concepts without notes (System One, Jev, Choice / Score / Noul, state→typed probs)
- [ ] Can contrast System One vs LLM / System Two–style agents with examples
- [ ] Can teach the topic in 5 minutes
- [ ] Can apply it to one real task (Block 7 one-pager: router or agent middleware map)
- [ ] Can name when **not** to use Jev

## Out of scope

- Multi-week academy depth
- Full multi-agent production platform
- Deep Kahneman / neuroscience scholarship
- Vendor bake-offs as the day’s center
- Putting API keys in the vault

## Constraints

- Time box: ~350 focused minutes (seven pedagogy blocks)
- Ground claims in [[RESOURCES]] / [[reference/source-ledger]]
- Treat speed/cost multiples as vendor-reported until you measure them
