Why this hub exists

A lasting reference library for TypeSafe AI’s Jev (flagship System One model): fast, typed, probabilistic decisions for software — not chat.

Company site: typesafe.ai (not “typescript.ai”).

Success looks like

  • State core concepts without notes (System One, Jev, Choice / Score / Noul, state → typed probs)
  • Contrast System One vs LLM / agent loops with examples
  • Teach the topic in about five minutes
  • Sketch one real application (router or agent middleware map)
  • Name when not to use Jev

Out of scope

  • Multi-week academy depth
  • Full multi-agent production platform
  • Deep Kahneman / neuroscience scholarship
  • Vendor bake-offs as the center of the hub
  • API keys in the repo or vault

Notes on sources

  • Ground claims in primary TypeSafe docs and the source ledger
  • Treat speed/cost multiples as vendor-reported until you measure them on your workload
  • Study-pack “day plan” materials are reframed here as an untimed topic guide — this is not a one-day-mastery product site
