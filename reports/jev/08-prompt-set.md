## Room-craft decision packet (T5 / Create Your Own)

Paste into Studio → Report → Create Your Own, or let the W8 PS1 create `report_room_craft`. Full note: [[notebooklm-room-craft-decision-packet]].

Using only the sources, produce an Executive Decision Packet report for Jev (TypeSafe System One) — typed decisions for software.
This is a decision artifact for a high-stakes room, not a study essay and not a stack tour.
Ground every claim in the sources. Prefer primary docs and named lectures when present.
Mark silence explicitly. Do not invent numbers, benchmarks, dates, or case examples.

Hard rules
- Lead with the answer. No warm-up, agenda, or project history before the recommendation.
- If a fact is unknown, do not guess. Write: UNKNOWN — will be known by [date or milestone] via [owner/method]. Guessing destroys trust.
- Keep supporting reasons to three or fewer. Remove nondiagnostic detail rather than labeling it "FYI."
- Express value in the room's units: cash, risk, customers, or time.
- Separate Run (keep the lights on) from Change (strategic investment) if both appear; do not blend them into one story.

Required report structure (use these exact section headings)

## 1. First 60 seconds (spoken script)
Write a spoken opening the presenter can deliver in under 60 seconds. It must include, in order:
1. The recommendation / Ask (one breath).
2. Business impact or dated cost of no.
3. The decision needed today.

Also include a one-line Stakes Sentence in this form:
If we do nothing, [Value at Risk] by [Date]. If we act, [Outcome] by [Date] at [Cost/Risk].
If sources lack a concrete number or date, keep the slots visible and mark UNKNOWN with a known-by date. Do not fill gaps with plausible fiction.

## 2. Five-slide spine (titles + contextual reference)
Produce exactly five live-room slides. For each slide provide:
- Action title (full sentence conclusion, not a topic label). Titles alone must pass the Titles Test: reading only the five titles must carry the argument.
- One-sentence job of the slide (what the room should conclude).
- Body content outline (bullets only; max three reasons or proof points).
- Written So-what line that must appear on the exhibit.
- Source anchor or silence note.

Use this contextual map unless the sources mandate a clearer MECE order for Jev (TypeSafe System One) — typed decisions for software:
1. Ask + outcome — what to approve/decide and the enterprise result.
2. Why now / stakes — complication, urgency, dated cost of delay.
3. The change or options — what changes, or the option set with the recommended path.
4. Value proof — diagnostic evidence the investment or decision pays (BVS); include one human-value beat only if sources support a named person + number.
5. Decision today — cost, time, capacity stopped, residual risk, and the explicit ask / next 90 days.

Note the 5+20 rule in one line after the five slides: five slides in the room; deeper evidence stays in appendix (list appendix topics only; do not write the appendix).

## 3. Five killer questions (20-second answers)
For each question write a 20-second spoken answer, then a one-line elevate (strategic implication). If unknown, use the UNKNOWN — known-by pattern. Do not skip any question.

1. Why now?
2. What if we wait? (dated cost of no)
3. Who else has done this? (benchmark or analogue from sources only)
4. What are we stopping? (capacity / tradeoff)
5. What if this slips? (risk and recovery)

## 4. Uncertainty register
Table with columns: Gap, Why it matters to the decision, What will be known, By when, Owner or method.
Include every UNKNOWN from sections 1–3. If nothing is unknown, write "None — all decision-critical facts are sourced" and list the strongest source anchors.

## 5. Readiness falsifiers
Answer yes/no with evidence or silence:
- Can the Ask be stated in one breath?
- Is value named in cash, risk, customers, or time with a date?
- Would a CEO leaving at minute five still know the Ask and the cost of no?
- Do the five titles alone tell the story?
- Are Run and Change kept separate where relevant?

## 6. Silence and out of scope
List what the sources do not cover that a real room might still ask. Do not fill those gaps.
